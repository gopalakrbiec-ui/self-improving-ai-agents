# Self-Improving AI Agents — Interactive Handbook

An interactive research handbook synthesizing Stanford CS329A lecture themes: inference-time scaling, verification, agentic workflows, planning, reinforcement learning, search, evaluation, continual learning, and future research.

## Live site

Once GitHub Pages is enabled with **Settings → Pages → Source: GitHub Actions**, the site deploys automatically from `main`.

Expected URL: `https://gopalakrbiec-ui.github.io/self-improving-ai-agents/`

## What is included

- Interactive systems map and animated visualizations
- Inference-time scaling / pass@K lab
- Verification, ORM/PRM and meta-verification coverage
- ReAct, RLEF, Constitutional AI, LATS, SPRINT, SWiRL
- STaR, GRPO, DAPO and train-time scaling
- AlphaCode, Search-o1 / Search-R1 and research agents
- METR, GDPval, DeepScholar-style evaluation concepts
- Searchable primary-paper library
- Embedded Stanford CS329A lecture video library
- Responsive light/dark UI

This is an independent educational synthesis, not an official Stanford publication.
